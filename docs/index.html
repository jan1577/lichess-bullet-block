FAQ

Questions and answers

What does the extension do?

It removes Bullet games from lichess.org, with optional controls for Blitz games and puzzle variants.

What about privacy?

No data leaves your device. The extension stores only your settings locally in the browser.

Can I contribute?

Yes. The project is open source, and contributions are welcome in the repository.

How do I create an issue?

Use the GitHub issue tracker to report bugs. Open a bug report.

How do I suggest a feature?

Use the feature request template in GitHub. Suggest a feature.

Can I donate to support development?

This is a small project with little ongoing development effort. If you want to support chess tooling instead, consider donating to lichess at lichess.org/patron.

Will you support Chess.com?

It is not currently planned, but the project is open to contribution if someone wants to help add support.
